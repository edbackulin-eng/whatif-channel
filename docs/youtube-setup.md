# Підключення YouTube: Google Cloud Console, крок за кроком

Канал: **Hypothetica** (колишній Orange Cat Shorts).

Важливо зробити саме в цьому порядку. Пункт 3 (статус In production) — критичний:
у режимі Testing refresh-токен Google анулює через **7 днів**, і автозаливка
мовчки помре за тиждень після налаштування.

---

## Крок 1. Новий проєкт

1. Відкрий **console.cloud.google.com**
2. Угорі, ліворуч від рядка пошуку — випадайка вибору проєкту. Натисни її
3. У вікні праворуч угорі — **New project**
4. **Project name:** `whatif-channel`
5. **Location:** No organization (якщо іншого не запропонує)
6. **Create**
7. Дочекайся сповіщення і **переконайся, що зверху обрано саме `whatif-channel`**,
   а не попередній проєкт. Це найчастіша помилка: далі все вмикається не там.

## Крок 2. Увімкнути YouTube Data API v3

1. Ліве меню (три риски) → **APIs & Services** → **Library**
2. У пошуку: `YouTube Data API v3`
3. Відкрий картку → **Enable**
4. Має з'явитися сторінка керування API — значить увімкнено

## Крок 3. OAuth consent screen → External → In production

Це той крок, який рятує токен від 7-денного згорання.

1. **APIs & Services** → **OAuth consent screen**
2. **User Type: External** → **Create**
   (Internal недоступний без Google Workspace — це нормально)
3. **App information:**
   - App name: `Hypothetica Uploader`
   - User support email: твоя пошта
   - App logo: не обов'язково (логотип тягне за собою перевірку бренду — пропусти)
4. **App domain:** можна лишити порожнім
5. **Developer contact information:** твоя пошта → **Save and continue**
6. **Scopes:** нічого не додавай тут → **Save and continue**
   (скоупи запитує сам застосунок під час авторизації)
7. **Test users:** додай свою пошту → **Save and continue**
8. **Summary** → **Back to dashboard**
9. **Тепер головне.** На сторінці OAuth consent screen знайди блок
   **Publishing status: Testing** і натисни **PUBLISH APP** → **Confirm**

   Статус має стати **In production**.

   Google покаже попередження про верифікацію — це нормально. Застосунок
   працюватиме і без неї; верифікація потрібна лише щоб прибрати екран
   "Google hasn't verified this app", який ти побачиш один раз при авторизації.

   **Якщо залишити Testing — refresh-токен помре через 7 днів.**

## Крок 4. OAuth client, тип Desktop

1. **APIs & Services** → **Credentials**
2. **+ Create credentials** → **OAuth client ID**
3. **Application type: Desktop app**
4. **Name:** `whatif-desktop`
5. **Create**
6. У вікні, що з'явиться — **Download JSON**
7. Збережи файл як:
   ```
   C:\whatif-channel\client_secret.json
   ```
   Ця назва вже в `.gitignore`, у репозиторій не потрапить.

---

## Крок 5. Скажи мені

Коли файл на місці — напиши. Я запущу локальну авторизацію: відкриється
браузер, ти підтвердиш доступ для каналу **Hypothetica**, і я покажу назву та ID
каналу, який відповів.

**Refresh-токен я покладу в GitHub Secrets лише після того, як ти підтвердиш,
що це саме Hypothetica.** Якщо на акаунті кілька каналів, Google може віддати
не той.

Що саме запитуватиметься:
- `youtube.upload` — заливати відео
- `youtube.force-ssl` — обкладинки, субтитри, метадані
- `youtube.readonly` — прочитати назву каналу для перевірки

## Після цього: квота

**Аудит не потрібен, щоб почати.**

Раніше я написав тут, що до аудиту відео примусово лишаються `private` і їх не
зробити публічними навіть вручну. **Це неправда, і перевірено на фактах.**
Канал зі стоїцизмом заливає через API з неаудитованого проєкту, і відео
виходять публічними за розкладом: відео від 10, 11 і 12 жовтня відкриваються
публічно, а заплановане на сьогодні ще закрите просто тому, що його час не
настав.

Лишається одне реальне обмеження:

**10 000 units на добу.** Одна заливка = 1 600 units, тобто ~6 відео на добу.
П'ять на тиждень проходять із великим запасом.

### Як вмикаємо

Автозаливка вмикається одразу після авторизації. Перше відео йде як перевірка:
заливається `private` з `publishAt`, а після настання часу публікації пайплайн
питає в API, чи статус став `public`.

Якщо YouTube раптом залишить його примусово закритим — ми це побачимо з
перевірки, і тоді подамо заявку на аудит. Текст заявки лежить напоготові в
`docs/youtube-audit-application.md`, але подавати його наперед не треба.
